# Paper drafts

`paper.md` and `paper.bib` are a draft software description in the Markdown
format of the Journal of Open Source Software (summary, statement of need,
state of the field, software design, research impact). The SoftwareX
Original Software Publication uses the journal's own Word or LaTeX template
(https://www.sciencedirect.com/journal/softwarex/publish/guide-for-authors)
with five mandatory sections and a code metadata table; the text here can be
reused for it, and the filled-in metadata table is in
`docs/softwarex_checklist.md`.
